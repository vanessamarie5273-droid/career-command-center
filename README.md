# Career Command Center

A private career intelligence and opportunity platform: 146 researched target companies, live openings from employers' own job boards, explainable fit scoring, a 14-stage application CRM, a resume library with ATS checks and exports, contacts, compensation scenarios, alerts with a daily briefing, and an assistant that answers from the database.

- Stack: Next.js 15, TypeScript, Prisma, PostgreSQL.
- Setup and deployment: [SETUP.md](SETUP.md).
- Tests: `npm test`, covering dedupe, stage transitions, scoring, link integrity, end-to-end ingestion on fixture feeds, and backup round-trips.
